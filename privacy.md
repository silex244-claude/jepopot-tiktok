# Privacy Policy

Last updated: August 31, 2026

## Jepopot TikTok Analytics

Jepopot TikTok Analytics is a personal tool used to access and analyze TikTok account information through TikTok's official APIs.

## Information Accessed

With the user's authorization, the application may access TikTok profile information, account statistics, and public video information made available through the TikTok API.

This may include profile information, follower and following counts, likes, video count, and information about public TikTok videos.

## How Information Is Used

The information is used only for personal analytics, content analysis, and reviewing TikTok account performance.

## Data Sharing

TikTok information accessed by this application is not sold to third parties.

## User Authorization

TikTok data is accessed only after the TikTok user authorizes the application through TikTok's official authorization process.

## Contact

For questions regarding this Privacy Policy, please contact the application owner through the project's GitHub repository.
